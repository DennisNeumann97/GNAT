# GNAT
Galaxy Nonlinear Alignment Tool (GNAT) for calculating model predictions for nonlinear galaxy alignments in simulation boxes (as of now).

It can do gg, g+, ++, and xx in multipole and projected correlation function for simulation boxes. 

**THIS IS A VERY EARLY ALPHA AND DOES NOT HAVE PROPER DOCUMENTATION AT MANY POINTS. A PYPROJECT.TOML WILL BE ADDED SOON**
